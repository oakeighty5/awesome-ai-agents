# Contributing to Awesome AI Agents

Thank you for your interest in contributing! This list is community-driven and we appreciate every suggestion.

## Guidelines

### What qualifies for inclusion

- The project must be **directly related to AI agents** (frameworks, tools, platforms, or resources).
- Open-source projects should have a **public repository** with a clear README and license.
- Commercial tools or platforms are acceptable if they offer meaningful free tiers or open-source components.
- The project should be **actively maintained** (commits within the last 12 months, unless it is a foundational/historical project).
- Learning resources should be **high quality and freely accessible**.

### What does NOT qualify

- Projects that are forks with no meaningful changes.
- Abandoned projects with no activity for over 2 years (unless historically significant).
- Self-promotional links without genuine community value.
- Duplicates of existing entries.

## How to add an entry

1. **Fork** this repository.
2. **Add your entry** to the appropriate category in `README.md`.
3. Use the following format:

   ```markdown
   - [Project Name](https://github.com/owner/repo) — One-line description that explains what makes this project useful.
   ```

4. Keep descriptions **concise** (one sentence, under 150 characters if possible).
5. Add entries in **alphabetical order** within their category.
6. If a project fits multiple categories, place it in the **most relevant one**.

## Pull request format

- **Title**: `Add [Project Name]` or `Update [Project Name]`
- **Description**: Include a brief explanation of why this project belongs on the list.
- One project per pull request (unless you are adding a new category with multiple entries).

## Quality bar

Before submitting, ask yourself:

- Would I recommend this to a colleague who is building AI agents?
- Does this project offer something unique compared to existing entries?
- Is the project well-documented enough for someone to get started?

## Suggesting a new category

If you think a new category is needed, open an issue first to discuss it. Include at least 3 projects that would fit the proposed category.

## Updating existing entries

If a project URL has changed, a description is inaccurate, or a project has been archived, please submit a PR with the correction.

## Code of Conduct

Be respectful and constructive in all interactions. We're here to build a useful resource together.
